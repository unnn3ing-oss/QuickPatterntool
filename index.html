QuickCut 影片剪輯已經搬家了

多軌時間軸剪輯已獨立成專屬網站，這個分頁不再提供剪輯。下面輪播介紹它的功能，按右下角的「前往 QuickCut」就能過去（會在新分頁開啟）。

功能 1／4

多軌時間軸剪輯

把影片、音訊、圖片排進時間軸，剪成一支影片。版面是左邊媒體庫、中間檢視器、右邊詳細內容，下面是時間軸。

  1. 匯入影片、音訊或圖片，用入點、出點選好要用的範圍，再插入、覆蓋、替換或加到結尾。
  2. 工具有選取、刀片、修剪（滾動、波紋、滑移、滑動），也有對應的快捷鍵。
  3. 影片的畫面與聲音會自動連結，可以分開調整。

功能 2／4

轉場特效與字幕

兩段影片中間可以加轉場，字幕可以直接打，也能匯入整份 SRT。

  1. 8 種轉場：交叉疊化、淡出到黑、擦除、推移等；兩段相接是雙邊轉場，開頭與結尾則是淡入、淡出。
  2. 相接的兩段影片都有聲音時，轉場會自動做聲音交叉淡化。
  3. 字幕有彈出、逐行彈出、逐字彈出、跳起等字體特效，可以匯入、匯出 SRT（UTF-8、Big5 都能讀）。

功能 3／4

專案檔與自動暫存

剪到一半也不怕：進度可以存成專案檔，隔天接著剪。

  1. 「儲存專案」會下載一個 .qcut 檔，只存剪輯資料，不含影片素材，所以只有幾 KB。
  2. 「開啟專案」（或直接把專案檔拖進畫面）會還原進度，缺的素材可以一鍵接回，或選素材所在的資料夾自動配對。
  3. 每次改動約 1.5 秒就自動暫存在瀏覽器裡，不小心關掉分頁，下次開啟會問你要不要還原。

功能 4／4

匯出成 MP4

剪好就直接匯出 MP4，多數播放器和社群平台都能用。

  1. 瀏覽器支援時輸出 H.264 ＋ AAC，否則退為 VP9 ＋ Opus。
  2. 素材全部在你的瀏覽器裡處理，不會上傳到任何伺服器。
  3. 建議用最新版 Chrome 或 Edge（匯出用 WebCodecs），桌面瀏覽器專用。

套版產生器使用說明

切換功能

  • 上排中間可以在「圖片套版」「浮水印」「拼圖」「尺寸」之間切換（點一下，或直接用滑的），兩邊的內容各自獨立、互不影響。圖片套版一律用多組的方式，沒有單張／批次的切換。

浮水印

  • 把照片拖到左上角的區域（或點擊選取、Ctrl+V 貼上），可以一次放多張；多張時預覽下方會出現展示窗，點一張就能預覽，也能按 ✕ 移除。
  • 預設自動把 Logo 放在每張照片四個角裡最暗的地方（每張各自判斷，幾乎一樣暗時放右上角），疊上新版 TVBS NEWS Logo（大小 13%、邊距 3%、不透明）；「浮水印圖」可以切換成舊版「新聞網」Logo，或自己上傳的圖（建議用背景透明的 PNG 或 SVG）。
  • 位置只有四個角（左上、右上、左下、右下）。在預覽上直接拖曳 Logo（抓的範圍比 Logo 大）只會改目前這一張，它會吸附到最近的角；按左側的位置鈕則是全部照片一起改（按四個角＝全部放同一角，按「自動（最暗的角）」＝回到每張各自判斷），如果有照片已經單獨調整過，會先問你要不要全部改掉。「大小」「透明度」「邊距」套用到所有照片。
  • 下載的檔案維持原圖尺寸，格式可「沿用原圖」或指定 JPG（品質 95%）／PNG，檔名是「原檔名_浮水印」。「下載本張」維持原檔名；「全部下載」的檔名是「YYMMDDHHMM_第幾張」（例如 2610122312_1，時間是按下按鈕那一刻的，每張間隔 0.5～1 秒），瀏覽器第一次可能會詢問是否允許下載多個檔案。

拼圖

  • 一張 1080 寬的畫布，把多張照片無縫拼在一起。「等分」可把畫布切成直向、橫向各 1～4 份，在預覽上拖曳格子之間的分隔線可調整每格比例；「自由框」可以自己拖曳拉出矩形框（最多 12 個）、移動、拉邊角改大小，靠近邊緣會自動貼齊，也能調整上下層、刪除，並調整畫布高度做直式長圖。
  • 照片用拖曳放進格子、點擊選取、Ctrl+V 貼上（貼到目前選取的格子），一次選多張會依序放進空的格子。拖曳照片調整位置，滑鼠停在格子上用滾輪或左側滑桿縮放。
  • 下載是 1080 寬、300 DPI 的 JPG（品質 95%），檔名「yyyymmdd拼圖」；「複製圖片」會把成品放進剪貼簿。

尺寸

  • 把照片拖進來（或點擊選取、Ctrl+V 貼上，可一次放多張），輸入想要的寬和高，所有照片一起轉成這個尺寸。
  • 「裁切填滿」：寬、高都要填，照片會縮放到剛好蓋滿，多出來的部分裁掉；在預覽上拖曳可以調整保留哪一塊（每張照片各自記住）。「等比縮放」：寬、高只填一個，另一邊自動依原圖比例算；兩個都填時，會縮到剛好放進這個範圍內，不裁切。
  • 輸出格式可「沿用原圖」或指定 JPG（品質 95%）／PNG。「下載本張」檔名是「原檔名_寬x高」；「全部下載」的檔名是「YYMMDDHHMM_第幾張」。尺寸上限 10000 像素；放大比原圖大的尺寸會變模糊。

圖片套版：設定每一張圖

  • 每一組都先選擇「類別」：新聞（藍框）或娛樂（粉框），會影響套版右上角的角標樣式。
  • 在「標題」欄貼上或輸入文字，按 Enter 換行，會照原樣分行顯示在圖上。
  • 「背景」可選擇「圖片背景」或「純色背景」：圖片背景支援點擊選取、拖曳檔案，或直接 Ctrl+V 貼上；純色背景可從色票挑選。
  • 「字級」對照的是 Canva 字級：使用圖片背景時固定為 50，無法調整；純色背景預設 60，可以用 − ＋ 調整。
  • 預覽上滾輪縮放、拖曳調整位置，點兩下可直接輸入標題。

範例成品

圖片套版：多張與下載

  • 按「＋ 再做一張」可新增一組新的圖卡設定，每一組都能各自設定類別、標題、字級與背景。
  • 每組按「完成」可單獨產生該組的圖，完成後該組會自動收合，要再編輯可點預覽下方的縮圖或該列；編輯中想先收起來，點該組標頭（「圖片 #N」那一列）或編輯框外圍即可，不必按完成；或按上方「全部完成」一次產生所有尚未完成的組別，缺標題或背景的組別會被略過並提示原因。
  • 每組編輯區上方的「下載」可以只下載這一組（尚未完成會先自動完成）；「移除」會先跳出確認框，避免誤刪。
  • 同時間只會展開一組的編輯區，其餘組別（不論完成與否）都會收合成一列；點任一列可重新展開該組編輯。
  • 右側預覽區的畫布下方，會以可左右滑動的縮圖展示窗（可用兩側箭頭、滾輪或觸控板左右捲動）顯示「每一組」的狀態：已完成的顯示成品縮圖，尚未完成的則保留標題文字並標示「未完成」。點任一張縮圖都會跳到並展開對應組別的編輯區。
  • 預覽畫布下方會同步顯示該組標題（換行處自動接成全形空格），方便在很多組別時快速確認目前看的是哪一張。
  • 預覽區會懸浮跟隨畫面捲動，即使批次組數很多、編輯區拉得很長，也不用捲回最上方才能看到預覽。
  • 拖曳圖片檔案或直接 Ctrl+V 貼上圖片，可以直接對著「標題」輸入框操作，不必先點進下方的圖片上傳區。
  • 按「全部下載」時，如果每一組都有標題和背景，會自動全部完成並依序下載；如果有組別還缺標題或背景，會先詢問「有未完成的套圖，要先下載已完成的嗎？」，確認後只下載有標題和背景的組別。
  • 「全部清除」（在「＋ 再做一張」左邊）會清空所有組別（會先跳出確認框）。

確定要全部清除？

這會清空目前畫面上的所有設定，且無法復原。

安裝 Chrome 插件

只要做一次，約 3 分鐘。裝好之後，插件會自己提醒你更新。

步驟 1／6

建立放插件的資料夾

網頁沒辦法直接替瀏覽器安裝插件，所以要先在電腦上準備一個資料夾放插件檔案，再到 Chrome 載入一次。

建議的資料夾名稱（按一下複製，不用自己打）

QuickPatterntool
  1. 先按下面的「下一步」，到步驟 2 按「選擇資料夾並寫入」，會跳出選擇資料夾的視窗。
  2. 在視窗裡按「新增資料夾」（Mac 叫「新增檔案夾」），貼上剛剛複製的名稱（Ctrl + V）後按 Enter。
  3. 選取那個新資料夾，按「選擇資料夾」。

小提醒　Chrome 不允許直接選「下載」「文件」「桌面」這幾個資料夾本身，請在它們裡面新增或選一個資料夾。選到已經有東西的資料夾時，我會在裡面自動建立同名資料夾，不會動到你原本的檔案。

步驟 2／6

下載最新版插件檔案

從 GitHub 下載最新版，直接寫進步驟 1 建好的資料夾。

  1. 按「選擇資料夾並寫入」，選步驟 1 建好的資料夾，再按「選擇資料夾」。
  2. Chrome 會問「要讓這個網站編輯資料夾裡的檔案嗎？」，請按「編輯檔案」（只會寫入插件檔案）。
  3. 等到出現「已把 N 個檔案寫入」就完成了，按「下一步」。
瀏覽器不能選資料夾，或想自己解壓縮？改用 ZIP

按「改下載 ZIP」，下載後先解壓縮（Windows：在 ZIP 上按右鍵 →「全部解壓縮」；Mac：連點兩下）。步驟 5 要選的是解壓縮後、打開就看得到 manifest.json 的那一層資料夾。Windows 解壓縮後常會多包一層，要再點進去一層。

步驟 3／6

開啟 Chrome 的擴充功能頁

網頁不能替你開啟這個頁面，請複製網址，自己貼到 Chrome 的網址列。

chrome://extensions
  1. 在 Chrome 按 Ctrl + T 開一個新分頁（也可以點分頁列最右邊的「＋」）。
  2. 按 Ctrl + V 把剛複製的網址貼到網址列，再按 Enter。
  3. 看到標題寫著「擴充功能」的頁面就對了，保持開著，接著做步驟 4。

另一個方法　點 Chrome 右上角的「⋮」→「擴充功能」→「管理擴充功能」，也會到同一個頁面。

步驟 4／6

打開「開發人員模式」

這個插件不是從 Chrome 線上應用程式商店安裝的，所以要先打開「開發人員模式」，Chrome 才允許載入自己的資料夾。

  1. 在擴充功能頁的右上角，找到「開發人員模式」開關。
  2. 點一下開關，變成藍色就是打開了。
  3. 打開後，左上方會多出「載入未封裝項目」「封裝擴充功能」「更新」三個按鈕，下一步會用到第一個。

小提醒　偶爾重開 Chrome 時，會跳出關於「開發人員模式擴充功能」的提醒，直接關掉就好，不要按「停用」。

步驟 5／6

載入插件

接下來告訴 Chrome：插件檔案放在哪個資料夾。

要選的資料夾

QuickPatterntool
  1. 按擴充功能頁左上角的「載入未封裝項目」。
  2. 在跳出的視窗，找到上面這個資料夾，點一下選取它。
  3. 按右下角的「選擇資料夾」（Mac 上可能顯示「選取」或「開啟」）。
  4. 清單裡出現「圖片套版產生器」，就載入成功了。
出現「無法載入擴充功能」或「找不到 manifest」？

代表選到上一層了。請再往裡面點一層，直到打開資料夾就能直接看到 manifest.json、app.js 等檔案，再選那一層。用 ZIP 解壓縮的話，最常多包一層。

步驟 6／6

釘選到工具列，開始使用

裝好了！最後把插件釘選在 Chrome 工具列，以後一鍵就能打開。

  1. 點網址列右邊的拼圖圖示（擴充功能）。
  2. 在「圖片套版產生器」右邊按圖釘，變成藍色就是釘選好了，圖示會出現在工具列。
  3. 點工具列上的「圖片套版產生器」圖示，畫面右側就會打開側邊欄。
  4. 貼上文章網址、按 Enter，就能快速產圖。

之後要更新　不用回到這裡。側邊欄最下面按「版本更新」→「檢查更新」→「更新到最新版」；每次打開側邊欄也會自動檢查，有新版會跳出提醒。
