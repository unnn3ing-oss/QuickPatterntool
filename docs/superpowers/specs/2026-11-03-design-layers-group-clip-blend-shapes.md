前提：建立在 P0 規格與 `2026-10-30-design-paint-recolor-arc.md` 之上。只動網頁版專用檔，**不升版**。`DOC_VERSION` 維持 1：只新增欄位，舊專案檔不用轉換；舊版程式讀到新檔案時，會被 `validate` 擋下並顯示中文原因。

## 0. 資料模型總覽（新增的部分）

```
頁面 { …, groups: { [gid]: { name, clip } } }   // 新增；沒有群組時是 {}
物件共通 { …, name?, groupId?, blend }           // name：圖層名稱（可省略）；groupId：所屬群組；blend：混合模式
shape.kind 新增 'polygon' | 'star'
shape（polygon）{ sides }                        // 3～12，預設 6
shape（star）   { points, inner }                // points 3～20 預設 5；inner 0.1～0.95 預設 0.5
```

- **群組只有一層（扁平）**［預設］：物件帶 `groupId`，群組本身的資料放在 `page.groups`。不支援巢狀群組，選取、命中測試、渲染、換色都不必改成遞迴，複雜度低很多。
- **不變式**（`validate` 要檢查，並給中文原因）：
  - 每個 `groupId` 都要存在於 `page.groups`。
  - 每個群組至少 2 個成員，而且成員在 `objects` 陣列裡必須**連續**，也就是在圖層順序裡是一整塊。
  - `page.groups` 裡沒有成員的群組不能留著。
  - `clip:true` 的群組，最上層的成員必須是 `rect`、`ellipse`、`polygon` 或 `star` 這四種形狀之一。
  - `blend` 必須在下面列的清單內。
  - `sides`、`points`、`inner` 在範圍內，而且是整數（`inner` 除外）。
  - `name` 是字串，長度 ≤ 40。
- `defaults` 補欄位：
  - 所有物件：`blend:'normal'`。
  - 形狀：polygon 補 `sides:6`；star 補 `points:5, inner:0.5`。
  - `migrate` 遇到舊檔：補 `page.groups = {}`，以及每個物件的 `blend`。

## 1. 多邊形與星形

- **幾何**：內接於物件的框（未旋轉），頂點分布在以框中心為圓心、半軸為 `w/2`、`h/2` 的橢圓上，第一個頂點朝正上方。
  - 星形外圈的頂點在橢圓上，內圈的頂點在 `inner` 倍的橢圓上，兩圈交錯。
- **外觀**：填色支援純色與漸層（和 rect／ellipse 相同），描邊照常。這兩種不支援圓角，`radius` 忽略。
- **工具列**：「形狀」區新增「多邊形」「星形」兩顆按鈕，預設尺寸 400×400［預設］。
- **面板**：
  - 種類下拉選單多兩個選項。
  - 多邊形有「邊數」數字欄位。
  - 星形有「角數」數字欄位，以及「內徑」滑桿（10～95%）。

## 2. 混合模式

- `blend` 的值，以及它對應的 Canvas `globalCompositeOperation`：

| `blend` | Canvas 值 |
|---|---|
| `normal` | `source-over` |
| `multiply` | `multiply` |
| `screen` | `screen` |
| `overlay` | `overlay` |
| `darken` | `darken` |
| `lighten` | `lighten` |
| `color-dodge` | `color-dodge` |
| `color-burn` | `color-burn` |
| `hard-light` | `hard-light` |
| `soft-light` | `soft-light` |
| `difference` | `difference` |
| `exclusion` | `exclusion` |
| `hue` | `hue` |
| `saturation` | `saturation` |
| `color` | `color` |
| `luminosity` | `luminosity` |

- **介面中文名稱**：正常、色彩增值、濾色、覆蓋、變暗、變亮、加亮顏色、加深顏色、實光、柔光、差異化、排除、色相、飽和度、顏色、明度（照 Illustrator 中文版）。
- **作用範圍**：文字、圖片、形狀、貼圖。馬賽克固定 `normal`：面板不顯示這個欄位，`validate` 也不接受其他值。
- **渲染**：每個物件畫到畫布時，把 `ctx.globalCompositeOperation` 設成對應值，畫完再還原。
  - 圖片原本就是先畫在自己的離屏畫布上，混合模式套在「畫回頁面」那一步。
- **面板**：放在所有物件共通的「透明度」下面，用下拉選單「混合模式」。

## 3. 群組

### core（純函式，全有或全無）
- `groupObjects(doc, pageId, ids, { clip = false } = {}) → { ok, gid }`
  - 選取的物件至少 2 個，而且都沒有鎖定。
  - 如果有物件本來就在別的群組裡：先把它們移出原本的群組；原群組剩不到 2 個成員時就解散。
  - 成員會搬到「選取物件中最上層那一個」的位置，排成連續的一塊，彼此的相對順序不變。
  - 新的 gid 依序為 `g1`、`g2`…（取現有最大號碼 +1）。名稱預設為「群組 N」；`clip:true` 時是「剪裁群組 N」。
  - `clip:true` 時，選取物件中最上層的一個必須是 rect、ellipse、polygon 或 star，否則回「剪裁遮色片要用最上層的形狀當外框」。
- `ungroup(doc, pageId, gid)`：拿掉所有成員的 `groupId`，刪掉群組資料。成員有任何一個鎖定時，回「物件已鎖定」。
- `groupOf(page, id) → gid|null`、`membersOf(page, gid) → ids`（依圖層順序）。
- 既有操作要維持不變式：
  - `removeObjects`：刪除後群組剩不到 2 個成員就解散；剪裁群組的外框形狀被刪掉時，整個群組也解散（剩下的物件留著，只是不再被剪裁）。
  - `duplicateObjects`、`pasteObjects`：整組都被選到時，複製出新的群組（新的 gid），否則副本不帶 `groupId`。
  - `reorder`：要調整的 ids 剛好是一整個群組時，整塊一起移動，而且不能插進別的群組中間；ids 只是群組裡的一部分時，只在群組內部移動。
  - `updateObjects` 不能直接改 `groupId`，要改只能透過 `groupObjects`／`ungroup`。
- `moveLayer(doc, pageId, ids, toIndex)`：給圖層面板拖曳用。`toIndex` 是移動完成後，這一塊最下層的那個在 `objects` 中的位置。規則同 `reorder`：不能把群組拆開，也不能插進別的群組中間；違反時回中文原因。
- `transformObjects(doc, pageId, ids, { scale, origin, rotate, center })`：多選或群組整組變形。
  - `scale`：等比例，以 `origin`（頁面座標）為基準縮放所有成員的位置與尺寸。文字的 `size`、`letterSpacing`、`stroke.w`、陰影的位移和模糊一起乘上比例；形狀的 `stroke.w`、`radius` 也乘上比例。
  - `rotate`：度數，以 `center` 為圓心，把每個成員的中心點繞著它轉，成員自己的 `rot` 也加上同樣角度。馬賽克不能旋轉：選取範圍裡有馬賽克時，`rotate` 回「馬賽克不能旋轉」。
  - 鎖定的物件不能被變形。
- `hitTest`：剪裁群組的成員，只有點在外框形狀的框內（考慮旋轉）時才算命中；外框形狀本身不畫出來，但點它的框內也算命中這個群組。

### 渲染
- **剪裁群組**：畫到群組的第一個成員時，先 `ctx.save()`，接著用外框形狀的路徑（套用它的位置與旋轉）`ctx.clip()`，畫其他成員（外框形狀本身不畫），最後 `ctx.restore()`。
- 一般群組照原本的順序畫，沒有額外處理。

### 介面
- **點選**：
  - 點到群組成員時，選取整個群組（所有成員）。
  - **雙擊**群組裡的物件，進入「群組內選取」，只選那一個成員；這時可以單獨移動或改屬性。Esc 或點空白處離開。
  - 群組內選取的是文字時，再雙擊一次才是編輯文字。
- **整組變形**（多選或群組）：
  - 外框只顯示 4 個角把手（等比縮放，以對角為基準）和 1 個旋轉把手（按住 Shift 每 15°），都呼叫 `transformObjects`。
  - 拖曳整段只記一筆復原，沿用 begin／rewind／end 的寫法。
  - 4 個邊把手不顯示［預設］：成員有旋轉時，非等比縮放沒有明確定義。
- **快捷鍵**（輸入框內不作用）：
  - Ctrl／Cmd＋G：群組
  - Ctrl／Cmd＋Shift＋G：取消群組
  - Ctrl／Cmd＋7：建立剪裁遮色片
  - Ctrl／Cmd＋Alt＋7：釋放剪裁遮色片
- **面板**：
  - 多選時：「群組」「建立剪裁遮色片」按鈕。
  - 選到群組時：顯示群組名稱（可以改）、「取消群組」；剪裁群組顯示「釋放遮色片」。另外沿用對齊、等距分佈、圖層順序。

## 4. 剪裁遮色片

- 建立：多選，選取範圍中最上層的物件是 rect、ellipse、polygon 或 star → 「建立剪裁遮色片」= `groupObjects(..., { clip: true })`。
- 外框形狀在畫布上不畫出（Illustrator 的做法）；被選取時，選取框照常顯示，而且畫出外框形狀的虛線輪廓。
- 釋放 = `ungroup`。外框形狀釋放後恢復可見，填色與描邊都保留原值。

## 5. 圖層面板

- **位置**：右側面板頂端分成兩個分頁「屬性｜圖層」［預設在屬性］，切換時記住選擇。手機版面一樣有這兩個分頁。
- **清單**：只列目前這一頁的物件，**最上層排在最前面**（跟 Illustrator 一樣）。每列依序是：
  - 類型小圖示
  - 名稱：有 `name` 就用它；沒有的話文字用「文字：」加前 10 個字，其他用類型名稱（圖片、矩形、橢圓、線、箭頭、多邊形、星形、貼圖、馬賽克）
  - 眼睛：切換 `hidden`
  - 鎖頭：切換 `locked`
- **群組**：顯示成一列可以收合的標題（▸／▾、群組名稱、眼睛、鎖頭），成員縮排列在下面。群組的眼睛和鎖頭會一次套用到所有成員。剪裁群組的標題旁標示「剪裁」，外框形狀那一列標示「外框」。
- **操作**：
  - 點一列：選取那個物件；點群組標題則選整組。Shift 點擊可以加選。點成員列等同「群組內選取」。
  - 畫布上的選取會同步反白對應的列。
  - 雙擊名稱可以改名：Enter 確認、Esc 取消；寫入 `name` 或群組的 `name`。
  - 拖曳列可以調整圖層順序，呼叫 `moveLayer`。整個群組只能從標題列拖曳；成員只能在自己的群組內拖曳。拖到不允許的位置時不動作，並顯示原因。
- **復原**：每一個動作（顯示／隱藏、鎖定、改名、拖曳）各記一筆。

## 6. 測試

- **core 單元測試**：
  - `validate`：群組的各項不變式（成員不連續、只有 1 個成員、`groupId` 不存在、剪裁群組最上層不是形狀）各一例。
  - `groupObjects`：成員排成連續一塊並保留相對順序；移出原群組後原群組自動解散；有鎖定物件時失敗；剪裁時最上層不是形狀就失敗。
  - `ungroup`、`removeObjects` 自動解散；刪掉剪裁外框後群組解散。
  - `duplicate`／`paste` 整組時帶新的 gid。
  - `reorder`／`moveLayer` 不會拆開群組，也不會插進別的群組。
  - `transformObjects`：等比縮放後，基準點的位置不變、文字 `size` 乘上比例；旋轉 90° 後成員的中心位置正確；有馬賽克時旋轉失敗。
  - 剪裁群組的 `hitTest`。
  - `blend`、`sides`、`points`、`inner` 的範圍檢查。
  - `migrate` 補 `groups` 與 `blend`。
- **render 單元／e2e（像素）**：
  - 多邊形 6 邊：中心有顏色；框的四個角落是背景色。
  - 星形：兩個尖角之間的凹處是背景色。
  - `multiply`：紅疊綠變黑。
  - `screen`：濾色結果變亮。
  - 剪裁：圓形外框裁切圖片後，框外的角落是背景色、圓內是圖片的顏色；外框形狀本身的填色沒有畫出來。
- **UI e2e**：
  - 加多邊形、星形；面板調整邊數後畫面跟著改變。
  - 選兩個物件按 Ctrl+G，點其中一個會選到整組；拖曳時兩個一起移動；Ctrl+Shift+G 取消群組。
  - 整組角把手縮放後兩個都放大；旋轉把手讓兩個一起轉。
  - 雙擊進入群組內選取，只移動一個成員。
  - 建立剪裁遮色片後畫布被裁切；釋放後恢復。
  - 混合模式選「色彩增值」後畫面像素改變。
  - 圖層面板：
    - 列的順序跟圖層順序相反（最上層排第一）。
    - 點列會選取物件；按眼睛會隱藏物件；按鎖頭後物件拖不動。
    - 雙擊可以改名。
    - 拖曳列會改變圖層順序。
    - 把成員拖出群組時，不會讓它離開群組。
  - 以上每一項各按一次 Ctrl+Z 都能還原。
  - 專案檔存了再開：群組、剪裁、混合模式、多邊形和星形都保留。
