## 1. 漸層填色（形狀與文字，含放射漸層）

### 資料模型
- 「顏料」（paint）可以是：
  - 純色字串：例如 `'#2f6fed'`，也就是現有的寫法。
  - 線性漸層：`{ type: 'linear', from, to, angle }`，`angle` 照 CSS 的定義（0°＝由下往上、90°＝由左往右），和背景漸層一致。
  - 放射漸層：`{ type: 'radial', from, to, cx, cy, r }`。
    - `cx`、`cy` 是中心點，以框的寬、高為準，0～1，預設 0.5。
    - `r` 是半徑，以框的「中心到角落的距離」為 1，範圍 0.05～2，預設 1。
- 用到 paint 的欄位：
  - `shape.fill`：`rect`、`ellipse`。
  - `text.color`。
- `line`、`arrow` 的 `fill`，以及所有 `stroke.color`、`shadow.color`，**維持純色**。
- 背景 `bg` 新增 `{ type: 'radial', from, to, cx, cy, r }`，與線性的 `{ type: 'gradient', ... }` 並存。舊的 `gradient` 不改名，以相容既有專案檔。
- 漸層的座標系是**物件自己的框（未旋轉、左上為原點）**，所以物件旋轉時漸層跟著轉。文字的漸層範圍＝文字框 `w × h`。
- `validate`：paint 只能是合法的純色字串，或上面兩種物件之一；`angle` 是有限數；`cx`、`cy` 在 0～1；`r` 在 0.05～2；`from`、`to` 是純色字串。
- `migrate`：舊檔的純色字串照原樣保留，不用轉換；`DOC_VERSION` 維持 1，因為只是新增，舊版程式讀到新檔會被 `validate` 擋下並給中文原因。

### 渲染
- 新增 `paintStyle(ctx, paint, w, h, scale) → CanvasGradient | string`，在物件的局部座標內建立漸層。
- 文字的描邊與陰影不受漸層影響：描邊用 `stroke.color`，填色用漸層。

## 2. 重新著色（整份或本頁換色）

### core（純函式、全有或全無）
- `colorKey(c) → '#rrggbb' | null`：吃 `#rgb`、`#rrggbb`、`rgb()`、`rgba()`，忽略透明度；看不懂就回 `null`。
- `docColors(doc, { pageId } = {}) → [{ color: '#rrggbb', count }]`
  - 給 `pageId` 只看該頁，不給就看全部頁。
  - 依出現次數由多到少排序，次數相同時依色碼排。
  - 收集來源：
    - 背景：純色，以及漸層的 from／to。
    - 形狀：fill（含漸層兩端）、stroke.color。
    - 文字：color（含漸層兩端）、stroke.color、shadow.color。
  - 隱藏物件也算；鎖定物件也算，但換色時會略過。
- `recolor(doc, map, { pageId } = {}) → { ok, changed, skippedLocked }`
  - `map` 是 `{ '#aabbcc': '#112233', ... }`，key 一律用 `colorKey` 正規化。
  - 替換時**保留原本的透明度**：原值是 `rgba(0,0,0,0.5)`、換成 `#ff0000`，結果是 `rgba(255,0,0,0.5)`。
  - 鎖定物件不改，算進 `skippedLocked`；背景也照換。
  - `changed` 是被改到的欄位數。`changed===0` 時回 `{ ok: true, changed: 0 }`，由 UI 顯示「沒有可替換的顏色」。

## 3. 弧形文字（沿圓弧排字）

### 資料模型
- `text.arc`：彎曲角度，單位度，預設 0（不彎），範圍 −360～360。
  - 大於 0：字排在圓的上緣，弧往上拱。
  - 小於 0：字排在圓的下緣，弧往下彎。
  - `|arc|` 是整行字實際佔用的圓心角。
- `arc ≠ 0` 時排成單行：`\n` 當成空白，不自動換行，`align` 也不作用。

### 渲染與排版
- 先量整行的寬度 `L`（逐字 `measureText`＋`letterSpacing`），半徑 `R = L / (|arc| × π/180)`。
- 字依序放在弧上：每個字以自己寬度的中點對齊弧上的位置，並旋轉成切線方向；整段弧的中點對齊框的水平中心。
  - arc > 0：弧頂貼齊框的上緣，往下留一個字高。
  - arc < 0：弧底貼齊框的下緣。
- `render.textHeight(obj, fonts)`：arc ≠ 0 時，回傳所有字四個角在框內 y 方向的包絡高度（數值計算），讓 UI 能把 `h` 設對。寬度 `w` 不變；字超出框的部分照畫，不裁切。
- 漸層、描邊、陰影、透明度、旋轉照樣作用。
- `layoutText` 的快取 key 要加上 `arc`。

## 4. 介面（`design-ui.js`）

- **顏料編輯器**：形狀的「填色」與文字的「顏色」改成：
  - 一排切換：純色／線性／放射。
  - 純色：一個色塊。
  - 線性：起點色、終點色、角度（0～360）。
  - 放射：中心色、外圍色、中心 X／Y（0～100%）、半徑（5～200%）。
  - 從純色切到漸層時，起點色沿用原本的顏色，終點色預設 `#ffffff`［預設］；從漸層切回純色時，用起點色。
  - 拉滑桿的一次拖動只記一筆復原（照現有 `liveBind` 寫法）。
- **背景**：類型多一個「放射」，欄位同上。
- **重新著色**：沒選物件時，頁面面板新增「配色」區。
  - 上方切換：本頁／全部頁［預設本頁］。
  - 下方是色票格：每格顯示顏色與次數；點下去開 `<input type=color>`，選好後套用 `recolor`，整次只記一筆復原，狀態列顯示「已替換 N 處」；有略過的鎖定物件時，再補一句「N 處在鎖定物件裡沒改」。
  - 最多顯示 24 色，超過的加一句「另有 N 色」。
- **弧形文字**：文字面板新增「弧度」滑桿（−360～360，旁邊有數字欄位，0 標示「不彎」）。改動後用 `render.textHeight` 更新 `h`。arc ≠ 0 時，對齊按鈕停用，並提示「弧形文字固定置中」。

## 5. 測試

- **core 單元測試**：
  - paint 的 `validate`：合法與不合法各 3 例以上。
  - `colorKey` 解析。
  - `docColors` 的計數與排序。
  - `recolor` 保留 alpha、略過鎖定、只換指定頁、全有或全無（map 裡有壞色碼時文件不變並回中文原因）。
  - `arc` 的範圍檢查。
- **render 單元測試**：用 stub ctx 測弧形排版。
  - `R` 的計算。
  - 第一個字和最後一個字對稱於中心。
  - `arc` 大於 0 與小於 0 的 `textHeight` 都大於 0。
  - 快取 key 有包含 `arc`。
- **render e2e（像素）**：
  - 線性漸層 90° 的矩形，左端接近 from、右端接近 to。
  - 放射漸層，中心接近 from、角落接近 to。
  - 旋轉 90° 的漸層矩形，漸層方向跟著轉。
  - 文字漸層，上下兩端顏色不同。
  - arc 180 的文字：框中央上緣有字的像素；框左下與右下角附近也有字（兩端彎下來）。
- **UI e2e**：
  - 把形狀改成線性與放射，畫布像素跟著改變；復原一次就回到純色。
  - 配色區點一格換色，畫面上那個顏色全部被換掉；按一次 Ctrl+Z 就全部復原。
  - 文字拉弧度後 `h` 改變、匯出 PNG 與畫布一致。
  - 專案檔存了再開，漸層與弧度都保留。
